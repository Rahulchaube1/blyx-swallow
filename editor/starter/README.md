# Swallow starter

Validate an exported payload's declared spans and checksum, then locate a byte.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Swallow** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
1
12976260
1
0
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/swallow) · [View the release](https://github.com/Rahulchaube1/blyx-swallow/releases/tag/v0.1.0)
